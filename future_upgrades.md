# Future Upgrades

## Features

### Full-Text Search Across Workspace
A search bar that allows searching for specific text content or tags across all markdown files in the currently opened directory.

### Git Integration
Display git statuses (modified, untracked, etc.) directly in the file tree, and allow viewing inline code diffs when a file has unstaged changes.

### Export to PDF/Word
A built-in feature to export the rendered markdown document as a self-contained PDF (e.g., using WeasyPrint or Puppeteer) or a `.docx` file for sharing.

### Command Palette
A quick-action menu (similar to Ctrl+Shift+P in VS Code) that lets you quickly search for files, toggle themes, or run editor commands without using the mouse.

### Presentation / Slideshow Mode
A mode that uses a library like Reveal.js to automatically convert markdown files separated by horizontal rules (`---`) into a full-screen interactive slideshow.

### AI Assistant Integration
A side panel hooked up to a local LLM or an API (like OpenAI/Anthropic) to help summarize documents, fix grammar, or suggest formatting.

### Custom CSS Theming
Allow users to easily supply their own `.css` files to customize the syntax highlighting and Markdown styling beyond the default GitHub-flavored styles.

### Real-Time Collaboration
Using WebSockets to allow multiple people on the local network to view and edit the same document simultaneously with live cursor tracking.
